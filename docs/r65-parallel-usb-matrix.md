Frames v108 r65 parallel USB repair matrix

This branch prepares four fail-closed EHCI variants (A-D) for parallel GitHub Actions evaluation. It is intentionally rooted in the last repository source branch currently available to the connector and does not claim to reconstruct the user's uploaded r64 ISO source. The matrix must fail rather than silently patch an uncertain source when expected r64/r61 EHCI anchors are absent.
